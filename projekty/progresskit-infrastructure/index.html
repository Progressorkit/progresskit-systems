Rozwiązanie

Konfiguracje Docker i Caddy opisują podział usług oraz trwałe wolumeny. Wydanie strony zawiera wyłącznie przejrzane pliki publiczne.

Architektura i technologie

  • Statyczny frontend i oddzielny backend API
  • Reverse proxy kierujące tylko wybrane endpointy
  • Dane usług poza katalogiem publicznej strony

Docker / Caddy / Linux / GitHub Actions / Python

Potwierdzony zakres

  • Kontener backendu z trwałym przechowywaniem SQLite
  • Fragmenty konfiguracji reverse proxy dla jawnych endpointów
  • Automatyzacja publikacji GitHub Pages i skrypt przygotowania artefaktu
  • Procedura backupu SQLite oraz wycofania wydania

Wyniki i granice weryfikacji

  • Repozytorium zawiera Dockerfile, fragment Compose i Caddy oraz procedury wdrożenia.
  • Audyt lokalny nie potwierdza aktualnego stanu VPS, backupów, HTTPS ani monitoringu.
