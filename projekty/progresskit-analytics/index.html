Problem

Rozwój portfolio wymaga informacji o wykorzystaniu strony bez dokładania zewnętrznego trackera i identyfikatorów urządzeń.

Dlaczego powstał

Rozwój portfolio wymaga informacji o wykorzystaniu strony bez dokładania zewnętrznego trackera i identyfikatorów urządzeń.

Rozwiązanie

Mały backend FastAPI zapisuje zdefiniowane typy zdarzeń w SQLite. Strona wysyła minimalne zdarzenia tylko na własnej domenie.

Architektura i technologie

  • Witryna → endpoint zdarzeń → SQLite
  • Wewnętrzne podsumowanie dostępne wyłącznie w zapleczu
  • Router produktu z odrębną bazą danych

Python / FastAPI / SQLite / Docker

Potwierdzony zakres

  • Endpoint zbierania odsłon oraz zdarzeń kontaktu i projektów
  • SQLite z indeksami czasu i typu zdarzenia
  • Wewnętrzne podsumowanie dla operatora
  • Osobna baza licznika APK i moderowanych opinii

Wyniki i granice weryfikacji

  • Kod nie definiuje pól IP, User-Agent ani identyfikatora urządzenia w bazie zdarzeń.
  • Sam endpoint health nie potwierdza integracji ani kompletności statystyk.
