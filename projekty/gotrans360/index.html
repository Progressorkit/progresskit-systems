GoTrans360

Prototyp systemu transportowo-logistycznego: panel dyspozytora, API tras i floty oraz demonstracyjny Smart Match.

PrototypŹródła: 2026-08-27
ProblemArchitekturaFunkcjeGaleriaWyzwaniaRozwójDostęp

Od potrzeby do produktu

Dla kogo

  • Przewoźnicy
  • Dyspozytorzy
  • Docelowo pasażerowie i nadawcy przesyłek

Problem

Ręczne planowanie przewozów i rozproszone dane o trasach, pojazdach i zapotrzebowaniu utrudniają wykorzystanie dostępnych miejsc i ograniczanie pustych przebiegów.

Dlaczego powstał

Sprawdzić wspólny model tras i floty oraz dopasowanie zapotrzebowania do przejazdów przed uruchomieniem pełnej usługi przewozowej.

Rozwiązanie

Monorepo zawiera panel WWW, osobny interfejs pasażera, API danych i model PostgreSQL. Smart Match oblicza propozycje dla scenariusza demonstracyjnego.

Architektura i technologie

  • Monorepo pnpm/Turborepo obejmuje panel dyspozytora, portal pasażera, API i współdzielone pakiety.
  • Next.js obsługuje interfejsy; Node.js i Prisma tworzą osobne API tras oraz floty.
  • Dopasowanie demonstracyjne używa odległości Haversine. Pełne połączenie frontendu z operacjami transportowymi pozostaje etapem rozwoju.

TypeScript / Next.js / React / Node.js / Prisma / PostgreSQL / PostGIS / Leaflet / Turborepo / pnpm

Potwierdzony zakres

  • Interfejs panelu dyspozytora i formularze kont
  • API operacji na trasach, pojazdach i przewoźnikach
  • Model danych PostgreSQL z Prisma
  • Demonstracyjne dopasowanie pasażerów do tras metodą Haversine
  • Widok mapy z przykładowymi znacznikami
  • Prototyp interfejsu pasażera bez aktywnej rezerwacji

Wyniki i granice weryfikacji

  • Raport z sierpnia 2026 potwierdza odczyt 12 567 syntetycznych tras przez bazę i API w izolowanym teście. Wynik nie oznacza obsłużonych przewozów ani ruchu produkcyjnego.
  • Historyczny benchmark trzykrotnie potwierdził dwie propozycje Smart Match dla dokładnie dwóch demonstracyjnych tras i dwóch zgłoszeń.
  • Audyt kodu rozróżnia API danych, ekrany demonstracyjne i planowany proces rezerwacji. Nie uruchamiano ponownie produktu podczas audytu portfolio.
