Realizacje WWW

Ignira / Maria-Salon

Strona stylistki paznokci: autentyczne prace, opis podejścia i przygotowanie wiadomości w sprawie terminu.

Etap do potwierdzeniaŹródła: 2026-08-24
ProblemArchitekturaFunkcjeGaleriaWyzwaniaRozwójDostęp

Od potrzeby do produktu

Dla kogo

  • Klientki stylistki paznokci
  • Lokalne marki usługowe

Problem

Osoba zainteresowana stylizacją potrzebuje zobaczyć wykonane prace i przekazać pomysł oraz preferowany termin w jednym miejscu.

Dlaczego powstał

Połączenie portfolio prac i uporządkowanego kontaktu w prostej witrynie.

Rozwiązanie

Statyczna strona z galerią i formularzem, który układa wiadomość, pokazuje jej treść i pomaga skopiować ją do rozmowy.

Architektura i technologie

  • Statyczny dokument HTML i osobne arkusze CSS
  • JavaScript obsługujący nawigację i przygotowanie wiadomości w przeglądarce
  • Kontakt przez zewnętrzne profile

HTML / CSS / JavaScript / WebP

Potwierdzony zakres

  • Galeria prac z opisami i obrazami WebP
  • Formularz zbierający rodzaj stylizacji, termin i inspirację
  • Przygotowanie wiadomości z podglądem i kopiowaniem
  • Odnośniki do profili kontaktowych
  • Menu mobilne z obsługą klawisza Escape
  • Ograniczanie animacji zgodnie z ustawieniem systemu

Wyniki i granice weryfikacji

  • Kod potwierdza przygotowanie wiadomości bez własnego systemu rezerwacji.
  • Kontrola składni JavaScript przeszła podczas audytu.

Materiały z produktu

Galeria zostanie uzupełniona po przeglądzie materiałów z produktu. Obecna prezentacja opiera się na opisanych źródłach.

Wyzwania i rozwiązania

Wyzwanie
Układ sekcji kontaktowej wymagał dopracowania na różnych szerokościach ekranu.
Analiza
Historia zmian pokazuje korektę siatki, szerokości pól, nagłówka i obszaru przycisku.
Przyczyna
Pierwotnego błędu nie odtworzono niezależnie; dostępny jest zapis poprawki układu.
Decyzja i poprawka
Wprowadzono jawne obszary siatki, ograniczenia szerokości pól i oddzielny blok akcji.
Weryfikacja
Porównanie zatwierdzonej zmiany z kodem oraz poprawna kontrola składni JavaScript; bez nowego testu przeglądarkowego.
Wynik
Poprawka znajduje się w źródłach. Bieżące działanie opublikowanej witryny pozostaje do potwierdzenia.
