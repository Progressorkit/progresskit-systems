# 🚀 PROGRESSKIT STUDIO // Vibewebstudio

Dedykowany ekosystem cyfrowy oraz portfolio projektów **Progresskit Studio** autorstwa Marka Zaworskiego. Strona wykorzystuje dynamiczny podział modułowy (SPA), stylizowany UI inspirowany estetyką cyberpunk/glassmorphism oraz interaktywny formularz briefu projektowego.

---

## 🌐 Podgląd na Żywo (Live Demo)

Strona jest w pełni wyrenderowana i dostępna pod adresem:  
👉 **[Progresskit Studio na GitHub Pages](https://progressorkit.github.io/Vibewebstudio/)**

---

## 💻 Stos Technologiczny

* **Frontend:** Czysty HTML5 + CSS3 (Glassmorphism, CSS Custom Properties, Responsive Web Design)
* **JS Engine:** Vanilla JavaScript (Dynamiczne ładowanie modułów `loadModule`, własny slider graficzny)
* **UX/UI:** Cyberpunk / Glass Dark Theme z akcentami cyjan/czerwień (`--ui-blue`, `--ui-red`)
* **Architektura:** Single Page Application (SPA) oparta na obiektach JavaScript

---

## 🛠️ Zawartość & Moduły Strony

* **HERO** – Pozycjonowanie marki, automatyzacja sprzedaży i eliminacja błędów operacyjnych.
* **ANALIZA** – Diagnostyka problemów i architektur rozwiązań VIBE (ERP/CRM, integracje AI).
* **DOWÓD (Case Studies)** – Prezentacja zrealizowanych projektów ze sliderami zdjęć:
  * *Lejek sprzedażowy* (Skalowalny system)
  * *System RWR* (Zarządzanie kontrolerami, redukcja czasu obsługi o 40%)
  * *Aplikacja Glikemia Premium* (Aplikacja mobilna dla diabetyków)
* **CENNIK** – Pakiety usług (`START`, `GROWTH`).
* **EDGE** – Wartości projektu: zero szablonów, kod na własność, pełen proces produkcyjny (.NET/AI).
* **BRIEF PROJEKTOWY** – Interaktywny interfejs generowania briefu i protokół komunikacji z możliwością bezpośredniego druku do PDF.
